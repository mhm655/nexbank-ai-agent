# Innovations: what this project adds beyond the brief's minimum

Brief refs: A1.4 (innovations that differentiate NexBank, p.5), Part B scoring (innovation counts in every level), the Innovator badge (three or more novel features, p.43), decision D-211. Every item below is a specification or a check that exists in this repository. Nothing was built, run or measured, so no item claims a result. Where a number appears, it is a proposal or a design value, not an outcome.

How to read the table: "Extends" names the brief requirement the item goes beyond. "Evidence" is the file to open.

## 2. Differentiation against A1.4

A1.4 gives a table of competitor behaviour. Using only that table, the project differs from it in these respects, each of which is specified above and not demonstrated: it escalates to a human from the first explicit request and not at a count (item 1); it says when it does not know instead of answering (item 2); it records what it did in a log that detects tampering and stops risky actions when the log is down (item 6); and it keeps its safety tests from being weakened by an update (items 4 and 8). These are claims about the design only. No comparison with a competitor system was made.
