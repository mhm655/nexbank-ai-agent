# Assumptions and Decisions

## Assumptions

| ID | Assumption |
|---|---|
| A1 | Deliverable is documentation-first: Markdown, Mermaid, YAML/JSON, CSV. Code limited to configs, test cases and an optional light harness. |
| A2 | The "500 customer transcripts" are not provided. The A1.2 category table is the data; representative examples are synthesised. |
| A3 | All rates and figures come from the simulated NexBank catalogue. No real-world rates. |
| A4 | Design is LLM-provider-agnostic; only interfaces are committed. |
| A5 | "Mid-stage startup" cost bounds apply, so a rough cost model is included. |
| A6 | Regulatory references are cited as the brief states them and verified against official sources where possible. |
